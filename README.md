## 📱 Personal Projects

### Auth.jc — Authentication & Navigation Demo
`React Native CLI` · `TypeScript` · `Firebase` · `Node.js`

Full authentication flow with JWT session handling and automatic refresh, SSL pinning, XSS input sanitization, Keychain-backed secure storage with biometric login (Face ID/Touch ID), persistent rate limiting, and OAuth with PKCE for GitHub sign-in.

### Sudoku.jc — Full Puzzle Game
`React Native` · `Expo` · `TypeScript` · `Zustand` · `SQLite`

Full playable Sudoku game with multiple difficulty levels, timer, hint system, custom puzzle generation logic, and smooth animations using React Native's Animated API. Global game state managed with Zustand, with local persistence via SQLite.

[![Repo](https://img.shields.io/badge/Repo-expo__sudoku__app-181717?style=for-the-badge&logo=github)](https://github.com/JuanEduardoCastro/expo_sudoku_app)

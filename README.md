### Pulse.Jc: Real-Time Chat with an AI Assistant
`React` · `NestJS` · `Socket.io` · `PostgreSQL` · `Prisma` · `TypeScript`

### Auth.Jc: Full-Stack Authentication Platform
`React Native CLI` · `TypeScript` · `Node.js` · `Express` · `MongoDB` · `Firebase` · `AWS`

React Native app paired with a Node.js/Express/MongoDB REST API. Email/password and OAuth login (Google, GitHub with PKCE, Apple), a 3-token JWT system with silent refresh, SSL pinning, biometric login (Face ID/Touch ID), push notifications with Firebase Cloud Messaging, and a 4-stage CI/CD pipeline to TestFlight and Play Console. API deployed on AWS EC2 behind Nginx.

### Sudoku.Jc: Full Puzzle Game
`React Native` · `Expo` · `TypeScript` · `Zustand` · `SQLite` · `Drizzle ORM`

Full playable Sudoku game with 4 difficulty levels, timer, hint system, and a backtracking generator that guarantees a unique solution. Global game state managed with Zustand, with a local-first data layer on SQLite and Drizzle ORM. Releases automated with EAS Workflows.
